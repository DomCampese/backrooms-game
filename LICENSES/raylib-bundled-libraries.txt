Third-party libraries bundled inside raylib
===========================================

raylib compiles these single-file libraries directly into libraylib, so they are
statically linked into every binary this project distributes — including the
.wasm served from the web build. Their notices are reproduced here because the
compiled object code carries no notices of its own.

Full license texts live at the end of each library's header in the raylib source
tree (src/external/), at the raylib version pinned by tools/web-build.sh.
